# rainsafe

O rainsafe é um aplicativo para alertas de chuvas intensas e pontos seguros em viagens.

Os objetivos do app são:
-Auxiliar motoristas e viajantes a identificar em tempo real áreas com chuvas intensas.

-Fornecer alertas sobre locais afetados por tempestades.

-Indicar pontos seguros para parada, ajudando na tomada de decisões para evitar áreas de risco.

Integrantes do trabalho: Daniel Lucas, Rikerson Antônio Freitas, Felipe Pereira da Silva e Pedro Tinnoco Lanna.
